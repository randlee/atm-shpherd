atm-shpherd

Multi-host control plane for defining, launching and observing ATM-backed agent teams. Successor to scmux; an application built on sc-runtime, not a fork.

Commands

  • shpherd — the operator CLI
  • atm-shpherd — the local daemon (database access, runtime adapters, sync, dashboard/API)

The CLI never opens SQLite or PostgreSQL directly.
