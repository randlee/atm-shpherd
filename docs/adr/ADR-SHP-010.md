# ADR-SHP-010 — MCP disabled in Phase B

- **Status:** Approved
- **Owner:** B3C
- **Decision:** Phase B exposes no MCP surface; enabling one requires a separate authenticated-surface ADR and plan.
- **Alternatives rejected:** generated generic database MCP commands or unauthenticated local tools.
- **Consequences:** generated MCP/general-row commands are removed or disabled.
- **Evidence:** route/command inventory and boundary tests prove no MCP endpoint is registered.
